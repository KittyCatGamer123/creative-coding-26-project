# Computational Arts Assignment 2026
*"Create an "Interactive Experience" using Godot entitled: "A Day in the Life of a First Year Game Design Student". I.e. YOU"*

This is a repository dedicated to the Computational Arts assignment I was to do for the second semester of college, which required us to develop a game centred around a "Day in the Life" of my life. 

We were required to make this game in the Godot Engine, using both elements of 2D and 3D systems, and to design our assets and sounds by ourselves. All code was written in GDScript and was to be published on Itch.io and Git.

**This project is still a work-in-progress. If you're reading this, hi!!! :D**

## Project Overview
The experience follows a slightly exaggerated version of my daily routine as a game design student. The game is broken down into 5 experiences:

1. Waking up and getting dressed.
2. Flagging down the bus.
3. Orderering a coffee at the café.
4. Taking notes during a lecture.
5. Quick assignment work in-class.

## Features
- Simple 3D enviornments and models made with CSGShapes.
- UI-based interactions, featuring hands of yours truely.
- Basic dialogue system for context.

## Tools Used
- Godot Engine & GDScript
- Photoshop
- Premiere Pro
- Beepbox.co

## Running the Game
The game can be played in-browser on the itch.io link:
- https://katrinaaster.itch.io/day-in-the-life-of-a-game-design-student

Alternatively, to run from the source code:
1. Clone the repository through `git clone https://github.com/KittyCatGamer123/creative-coding-26-project`.
2. Import the game into the engine through the `project.godot` file.
3. Run the Main Scene through F5, or Current Scene through F6.
